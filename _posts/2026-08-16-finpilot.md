> SK Networks Family AI Camp 5기 Final 프로젝트로 팀원들과 함께 만들었던 사이드 프로젝트, FinPilot을 정리해서 소개합니다.

### <i class="fas fa-rocket fa-fw"></i> **FinPilot이란**

FinPilot은 Google Docs에서 금융 문서를 더 쉽게 작성하고 편집할 수 있도록 도와주는 LLM 기반 Chrome 확장 프로그램이다. 실시간 초안 작성, 단락 생성, 요약 및 확장, 데이터 시각화 같은 기능을 금융 전문가와 비즈니스 사용자에 맞춰 제공한다.

### <i class="fas fa-lightbulb fa-fw"></i> **만든 이유**

금융 문서 작업은 반복적이고 시간이 많이 드는데, 정작 이 과정을 도와주는 도구는 대부분 문서 편집기 밖에 따로 떨어져 있었다. FinPilot은 LLM을 활용해 문서 작성과 데이터 처리 과정을 자동화하고, Google Docs 안에서 AI가 필요한 순간 바로 적용할 수 있게 만드는 데 초점을 맞췄다. 빠르게 성장하는 금융 시장과 AI 기술을 결합해서, 금융 전문가가 더 스마트하고 효율적으로 일할 수 있도록 돕는 게 목표였다.

### <i class="fas fa-list-check fa-fw"></i> **주요 기능**

FinPilot은 사이드 채팅 패널에서 아래 기능들을 바로 호출할 수 있다.

- **초안 작성** : 필요한 주제에 맞는 초안을 자동 생성해서 문서 작업의 시작을 간소화
- **단락 생성** : 특정 주제나 키워드를 기반으로 원하는 단락을 빠르게 작성
- **요약 및 확장** : 긴 텍스트를 간결하게 요약하거나, 추가 정보를 포함해 내용을 확장
- **데이터 시각화 (Web)** : 웹 데이터를 활용해 그래프와 차트를 생성
- **데이터 시각화 (Upload)** : 업로드한 CSV 파일 데이터를 기반으로 맞춤형 시각화 제공
- **실시간 협업** : Google Docs와 완벽하게 연동되어 결과가 바로 문서에 반영됨
- **AI 기반 문서 개선** : 문장 구조를 개선하고 보다 명확한 표현을 추천

### <i class="fas fa-star fa-fw"></i> **왜 FinPilot이 필요할까**

- 금융 전문가를 위한 AI 도구 — 금융 문서 작업과 데이터 분석에 최적화
- Google Docs 완벽 연동 — 별도의 설정 없이 바로 사용 가능
- 생산성 극대화 — 주당 평균 10시간 이상 절약 예상
- 사용자 친화적 UI — 직관적인 채팅 인터페이스로 누구나 쉽게 사용 가능
- 데이터 보안 최우선 — 사용자의 데이터를 제3자와 공유하지 않음

### <i class="fas fa-shield-halved fa-fw"></i> **보안 및 개인정보 보호**

- 모든 정보는 암호화되며, 사용자의 데이터를 제3자와 공유하지 않는다.
- 사용자 프라이버시를 최우선으로 고려해서 GDPR 및 개인정보 보호 원칙을 준수하며 운영했다.
